# SITL run — 2026-09-28 (ADR-019)

Full T06–T11 re-run after ADR-019 (orbit radius plumbed to guidance; CMD_START AMSL → height above
home; guidance code defaults aligned with YAML). Same stack as 2026-09-03: PX4 v1.16 SITL
`gz_tiltrotor` (4020), Gazebo Harmonic `shark_isr_coastal` (elevation 0.0), MicroXRCEAgent udp4:8888,
ROS 2 Humble. Stack started with `scripts/run_sim.sh` + `sitl_autopilot.sh` + `sitl_nodes.sh` +
`sitl_perception.sh`; exactly one instance of each node verified with `pgrep` before testing.

| Test | Result | Notes |
|---|---|---|
| T06 | PASS | 20/20, min=max=mean=30.00 m |
| T07 | PASS | PX4 exited OFFBOARD in 5.0 s → nav_state=2 |
| T08 | PASS | nav_state=5 (RTL). Run with `mock_detection_prob` 0.0 |
| T09 | PASS | after a manual CMD_DISARM — same no-auto-disarm-after-RTL finding as 2026-09-03 |
| T10 | PASS | 15.4 s; gate held on 5-frame burst, fired on 30-frame stream |
| T11 | PASS | TRACK 3.0 s after arming (t+69.1 s including the wait for IDLE) |
| ADR-019 manual | PASS | CMD_START `orbit_radius_m: 42`, `search_alt_amsl_m: 35` → SearchState `orbit_radius_m: 42.0`, GuidanceSetpoint TYPE_ORBIT `orbit_radius_m: 42.0`, orbit centre z 34.95 |

Findings:
- T09's first attempt failed ("mission did not reach IDLE within 120s"): after T08's RTL the
  vehicle sat at AGL 0.48 m, still armed. Disarmed via `AutopilotCommand.CMD_DISARM`, then passed.
  After T10's RTL, by contrast, it did auto-disarm (T11 waited ~65 s then proceeded). Intermittent.
- `scripts/sitl_stop.sh` left all five node processes running (mock_camera_node, detector_node,
  guidance_node, mission_node, autopilot_bridge); killed by PID.
- `scripts/sitl_nodes.sh` waits for `/vehicle_state` to appear in `ros2 topic list`, but
  `detector_node` (started by `sitl_perception.sh` at the same time) subscribes to it, which makes
  the topic appear before the bridge exists — guidance/mission started before the bridge.
